Lista Não Ordenada

Definição

A tag <ul> (Unordered List) é utilizada no HTML para agrupar itens em uma lista não ordenada.
Isso significa que a ordem dos elementos não altera o sentido do conteúdo — diferente de uma sequência de passos ou um ranking.

Estrutura Básica

Uma lista não ordenada é composta por dois elementos principais:

  • ul: tag container que delimita o início e o fim da lista
  • li: tag utilizada para definir cada item da lista

Tipos de Marcadores

O elemento ul tem os seguintes marcadores (bullets) através da propriedade CSS list-style-type.
Embora o atributo HTML type existisse em versões anteriores (HTML4), ele foi descontinuado e o padrão atual é utilizar CSS.

  • disc: Círculo totalmente preenchido. É o valor padrão dos navegadores.
  • circle: Círculo vazado (apenas o contorno)
  • square: Quadrado preenchido.
  • none: nenhum
